# Meter map

Read only rows for products in the traced path. These are investigation prompts, not a rate card. Open the linked official page on the audit date; verify the plan, billing status, included usage, rounding, and metric definition before calculating dollars. For another product, navigate from [Cloudflare's product index](https://developers.cloudflare.com/llms.txt) to its own `llms.txt` and pricing page.

| Product or trigger | Count separately | High-yield checks | Official source |
| --- | --- | --- | --- |
| Workers / Pages Functions | Inbound dynamic requests, CPU milliseconds, downstream bindings; check whether static assets or cache paths invoke the Worker | Duplicate mounts/polls, recursive service calls, CPU-heavy transforms, public hot routes. Outbound subrequests are not automatically another Worker request; inspect the actual destination. A WebSocket upgrade counts as a Worker request, its messages do not each become Worker requests. | [Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/) |
| Durable Objects / WebSockets | Requests/RPC sessions, incoming application messages under the current billing rule, alarms, active GB-seconds, SQL rows/storage or applicable backend | Per-gesture RPC/history, broadcast fanout, non-hibernating server sockets, DO-side timers, outbound sockets, wake/rebuild work. Protocol pings and outgoing messages have different request treatment; check the current rule. Hibernation eligibility and active duration are distinct from message volume. | [DO pricing](https://developers.cloudflare.com/durable-objects/platform/pricing/), [WebSocket hibernation](https://developers.cloudflare.com/durable-objects/best-practices/websockets/), [lifecycle](https://developers.cloudflare.com/durable-objects/concepts/durable-object-lifecycle/) |
| D1 | Rows read, rows written, storage, upstream Worker CPU | Use query `meta.rows_read` / `rows_written`, plans, and representative data size. A query returning one row can scan many; an index lowers reads but adds writes and storage. Count repeated auth and permission queries in the same action. | [D1 pricing and `meta`](https://developers.cloudflare.com/d1/platform/pricing/), [indexes](https://developers.cloudflare.com/d1/best-practices/use-indexes/) |
| R2 | Class A and B operations, GB-month, storage class, retrieval, minimum storage duration, any transform/delivery product | Per-object list/read/write, tiny frequently rewritten objects, cache-miss amplification, Infrequent Access objects deleted or replaced early. No egress fee does not mean no operations or retrieval cost. | [R2 pricing](https://developers.cloudflare.com/r2/pricing/) |
| Workers KV | Keys read/written/deleted, list requests, GB-month | Bulk calls still count keys; missing-key reads count. Look for per-event writes, repeated misses, fanout, refill after short TTLs. | [KV pricing](https://developers.cloudflare.com/kv/platform/pricing/) |
| Queues | 64 KB chunks for writes, reads, deletes; retry reads, dead-letter writes, consumer Worker work | A batch does not erase per-message operations. Trace poison messages, payload growth, visibility/retry settings, duplicate downstream effects. | [Queues pricing](https://developers.cloudflare.com/queues/platform/pricing/) |
| Cron / scheduled handlers | Trigger cadence, Worker requests and CPU, items scanned/run, downstream meters, overlap and retry | A job every minute that scans all tenants can dominate a lightly used service. Check skip/idempotency/leases and whether work repeats when nothing changed. Cron is a trigger, not a separate priced product. | [Cron triggers](https://developers.cloudflare.com/workers/configuration/cron-triggers/), [Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/) |
| Workflows | Invocations and CPU, steps, persisted GB-month, downstream product use | One Workflow or step per tiny event, unbounded polling, repeated state, retries or sleeping instances. Verify current step-count rules; step retries need not count as additional steps but can still cause CPU and downstream work. | [Workflows pricing](https://developers.cloudflare.com/workflows/reference/pricing/) |
| Workers Logs / traces / export / Log Explorer / Analytics Engine | Enabled and sampled log events, trace spans, exported events and destination charges, Log Explorer ingested/stored GB, Analytics Engine writes/queries | Invocation logs plus custom logs multiply per request; check environment-specific sampling. Tracing and Analytics Engine billing status can change. Log Explorer is volume-based, not query-count based; Logpush can also incur destination charges. Do not collapse these into one “observability” meter. | [Workers Logs](https://developers.cloudflare.com/workers/observability/logs/workers-logs/), [traces](https://developers.cloudflare.com/workers/observability/traces/), [OTel export](https://developers.cloudflare.com/workers/observability/exporting-opentelemetry-data/), [Log Explorer](https://developers.cloudflare.com/log-explorer/pricing/), [Analytics Engine](https://developers.cloudflare.com/analytics/analytics-engine/pricing/) |
| Workers AI | Model-specific neurons or equivalent token/image/audio units; daily included allocation | Repeated inference for unchanged content, duplicate embeddings, retry after successful work, missing cache or request caps. Verify the exact model and billing method. | [Workers AI pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/) |
| AI Gateway | Provider inference, Gateway logs under the account's first-gateway creation cohort, Guardrails inference, Unified Billing fees, Logpush | Core Gateway routing, caching, and rate limiting can be free while downstream provider calls and optional features are charged. Check creation date, logging configuration, paid features, and whether a retry crossed the provider boundary. | [AI Gateway pricing](https://developers.cloudflare.com/ai-gateway/reference/pricing/) |
| Vectorize | Queried vector dimensions and stored vector dimensions | A broad index or repeated query can cost more than the query count suggests; duplicate embeddings add storage and Workers AI work. Model index cardinality, dimensions, and query frequency. | [Vectorize pricing](https://developers.cloudflare.com/vectorize/platform/pricing/) |
| Containers, Browser Rendering, Images, Stream, other bound products | Product-specific active time, operation, storage, delivery, and third-party meters | A service can be expensive even if its Worker invocation count is small. Follow its current product index and metric page before excluding it. | [Cloudflare product index](https://developers.cloudflare.com/llms.txt) |

## Cross-meter checks

- Count the whole causal graph for one logical action. A Worker request, DO message, D1 scan, Queue operation, R2 read, inference call, and log event can all stem from it. Do not add unlike units together.
- Keep request counts, active lifetime, retained storage, and observability volume separate. A hibernating DO can still wake, receive billable messages, and perform storage work; an idle but hibernation-eligible DO does not accrue duration.
- Calculate marginal spend at the account level. Included usage may be shared, free-plan limits can fail rather than overbill, and a paid subscription already incurred is not saved by removing a few calls.
- Use provider counters to validate scale and source tracing to attribute cause. An aggregate usage graph alone does not identify a route; a source path alone does not establish deployment or billing.
